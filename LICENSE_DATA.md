# Dataset licence and attribution

This project includes a 5,000-row sample derived without changing source values
from the UCI Machine Learning Repository **Online Retail** dataset.

- Creator: Daqing Chen, London South Bank University
- Repository citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine
  Learning Repository. https://doi.org/10.24432/C5BW33
- Official dataset page: https://archive.ics.uci.edu/dataset/352/online-retail
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
  https://creativecommons.org/licenses/by/4.0/

The source covers historical transactions from December 2010 to December 2011.
It should not be interpreted as current retail market information.
